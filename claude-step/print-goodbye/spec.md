# Print Goodbye

Print different versions of "Goodbye World!" with varying exclamation marks.

## Instructions

For each task, use `echo` to print the exact string shown. Just print it, no other action is needed.

**Example:**
```bash
echo "Goodbye World!"
```

## Tasks

- [x] `echo "Goodbye World!"`
- [x] `echo "Goodbye World!!"`
- [ ] `echo "Goodbye World!!!"`
- [ ] `echo "Goodbye World!!!!"`
- [ ] `echo "Goodbye World!!!!!"`
