# Print Hello

Print different versions of "Hello World!" with varying exclamation marks.

## Instructions

For each task, use `echo` to print the exact string shown. Just print it, no other action is needed.

**Example:**
```bash
echo "Hello World!"
```

## Tasks

- [x] `echo "Hello World!"`
- [ ] `echo "Hello World!!"`
- [ ] `echo "Hello World!!!"`
- [ ] `echo "Hello World!!!!"`
- [ ] `echo "Hello World!!!!!"`
